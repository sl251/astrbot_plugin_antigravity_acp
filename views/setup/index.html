安装 CLI 与常见问题

安装后执行 agy --version，再回到本页重新检测。CLI 已安装但找不到：在插件配置填写 command 绝对路径，保存后重载。Windows 请指向 agy.exe。

需要代理：在插件配置选择 proxy_mode=custom 并填写 proxy_url，保存后重载。Docker 的 127.0.0.1 指容器自身。

安装、登录和对话必须处于 AstrBot 的实际运行环境，使用同一系统用户。
